# Pushup Bro 2.0: store texts and submission (instructions for Claude in Chrome)

You are working in the user's own Chrome, where they are signed in to App Store Connect (https://appstoreconnect.apple.com). The goal: put the final 2.0 texts into the App Store listing in all five languages, attach the in-app purchases and the build, and submit Pushup Bro 2.0 for review.

## Ground rules
- Work in a new tab. Go through the parts in order and tell the user briefly when each part is done.
- **Stop and ask the user before you:**
  - press **Submit for Review** (the very last step);
  - accept any agreement or change anything about tax, banking or pricing;
  - delete or replace anything that is already there (screenshots, videos, products), apart from the four text fields in Part 1, which you overwrite.
- Never type passwords, card numbers or secrets anywhere. If a page asks for a login or 2FA, ask the user to do it.
- Paste every text **exactly** as given below, including line breaks and the URLs. Don't translate, shorten or "improve" them. If a field rejects a text as too long, stop and tell the user which field and language.
- If a page looks different from what is described here, go by the field names and tell the user what you did.

## Part 2: build
1. On the 2.0 version page, scroll to **Build** and press **Add Build** (or the + next to it).
2. Pick the **newest 2.0.0 build** (the highest build number, uploaded by Codemagic). If no 2.0.0 build is listed, or it still says "Processing", stop and tell the user.
3. If App Store Connect asks about **export compliance**: the app uses only the standard encryption built into iOS (HTTPS). The Info.plist already declares this (`ITSAppUsesNonExemptEncryption`), so there's usually no question; if there is one, answer that the app uses no encryption beyond Apple's operating system, and tell the user what you chose.

## Part 3: in-app purchases
1. On the 2.0 version page, find **In-App Purchases and Subscriptions** and press **Select In-App Purchases or Subscriptions** (or the + next to it).
2. Tick all three: `pushup_bro_pro_weekly`, `pushup_bro_pro_yearly` and `pushup_bro_pro_lifetime`, and press **Done**.
3. If a product can't be selected because it's missing metadata (status "Missing Metadata"): open it, tell the user what is missing (often the review screenshot or a localization), and don't invent anything.

## Part 4: App Review information
1. Scroll to **App Review Information**.
2. **Sign-in required:** off. No demo account is needed.
3. **Contact information:** leave what's there. If it's empty, ask the user for their name, phone and email; don't make them up.
4. **Notes:** replace the notes with this text:
```
Pushup Bro counts pushups with the motion sensors of AirPods (AirPods Pro, AirPods 3 or later, AirPods Max) or, without AirPods, with the iPhone's front camera. To try it without AirPods: on Home, pick "Camera", tap "Start pushin'", prop the phone up about 1 m away and do a few pushups (or move your head up and down in view). Video is processed on the device only and never stored or sent.

No sign-in is needed. Everyone gets an anonymous account for the social features (Bros, today's leaderboard, island visits); the "Everyone" tab of the leaderboard shows other players. Signing in with Apple or Google is optional and only used to back up progress for Pro members.

Pushup Bro Pro: new players get 3 free days with everything unlocked, handled in the app, no payment needed. After that the paywall offers Weekly (pushup_bro_pro_weekly), Yearly (pushup_bro_pro_yearly) and Lifetime (pushup_bro_pro_lifetime). "Restore" is at the bottom of the paywall, which also opens from Settings > Pushup Bro Pro.

The account can be deleted in Settings > Account > Delete account.

The first visit to the Island plays a short story film; it can be skipped with "Skip" at the top right.
```
5. Press **Save**.

## Part 5: release and final check
1. **Version Release:** ask the user whether to release **manually** or **automatically** after approval, and set it.
2. Before submitting, check that the page shows no red warnings or missing fields. In particular:
   - all five languages have the new texts;
   - the build is selected;
