Game music goes here, one file per track (MP3). A track that's missing just
stays silent, so they can be added one at a time:

- home.mp3: the gym on the home screen (loop)
- island.mp3: the island (loop)
- jungle.mp3: the jungle clearing (loop)
- story.mp3: cutscenes and the Jungle Trek map (loop)
- challenge.mp3: daily quest challenges (loop)
- battle.mp3: Jungle Trek fights (loop)
- boss.mp3: the duel with King Komo (loop)
- victory.mp3: winning a stage or quest (jingle, plays once)

See docs/music_prompts.md for the prompts they were made from.
